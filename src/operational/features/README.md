# Módulos operacionais

Esta pasta receberá as telas do PWA por domínio, sem mover regras de negócio para componentes visuais.

- `dashboard`: visão inicial e atalhos.
- `cylinders`: botijão atual, troca e reserva.
- `history`: linha do tempo consolidada de ciclos e movimentações (implementado).
- `alerts`: central de alertas acionáveis e lembretes (implementado).
- `analytics`: indicadores e gráficos mobile com proteção de qualidade (implementado).
- `profile`: residência, aparência, dados, instalação e backup seguro (implementado).

As extrações serão feitas gradualmente nas próximas fases a partir de `OperationalApp.jsx`.
